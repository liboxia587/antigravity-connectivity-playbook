# AGY 连通性排障与恢复经验手册

> 记录于 2026-10-08 | 纯文档经验汇编

本手册用于帮助开发者在 Windows 环境下排查 AGY（Antigravity，AI 辅助编程客户端/智能体工具链，包含 CLI 与桌面端 IDE）与大模型后端服务交互时的连通性、代理、地区限制、认证和配额问题。

手册核心倡导“**分层排障、依据具体错误体决策、隔离验证、人工受控恢复**”的原则，提供一次真实的故障复盘记录与已知限制清单。

---

## 核心基线与状态表（2026-10-08 实测记录）

| 候选通道 | 测试方式 | 观察结果 | 状态与边界判定 |
| :--- | :--- | :--- | :--- |
| **候选 A** | 独立端口 CLI + 桌面端 | CLI 两次调用成功（返回码 0）；当时操作记录显示桌面端回复成功 | 仅代表当时单机实测记录可用；不代表长期稳定性 |
| **候选 B** | 独立端口 CLI | 单次 CLI 调用成功（返回码 0） | 仅完成单次 CLI 验证，未做桌面端验收，未验证稳定性 |
| **候选 C** | 独立端口 CLI | 返回明确错误体（`FAILED_PRECONDITION` / `User location is not supported`） | 真实请求被地区策略拒绝；仅排除该候选在当次环境的可用性，不代表该地区整体不可用 |

> **关键提醒**：
> 1. **不推广任何服务或地区**：本项目不提供、不销售任何网络服务，亦不对任何特定服务商或地区作背书。
> 2. **不承诺自动恢复与长期稳定**：网络环境动态变化，未验证自动切换与整机重启后的恢复能力。
> 3. **版本未完整记录**：当时环境未完整记录 Windows、AGY 客户端及各代理组件的具体版本号，无法声称全量精确复现。

## 关键认知注意项

- **错误体优先于 HTTP 状态码**：严禁仅凭 HTTP 400/401/403/429 盲目切换网络线路。应结合请求目标、错误体与上下文缩小原因范围（见 [诊断指南](docs/diagnosis.md)）。
- **短请求也可能消耗大量额度**：即使客户端发送的只是极短的测试 Prompt，底层也可能自动携带完整的会话上下文与工程索引，单次测试即可能消耗上万 Tokens（历史回执中单次记录约 1.17 万 Tokens）。
- **分层隔离**：排障时切勿直接篡改日常生产配置；主通道正常时坚决不切线，新通道必须先行隔离验证。
